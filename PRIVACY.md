# Privacy policy

Last updated: 16 November 2026

Pandite is an image viewer that works on your own computer. It collects no
data about you, and it sends nothing anywhere.

## What Pandite does not do

- It makes no network connection. The program contains no network code,
  and every release is checked for that before it is published.
- It has no account, no sign-in and no registration.
- It has no analytics, no telemetry, no crash reporting and no advertising.
- It shares nothing with the developer or with anyone else, because it has
  nothing to share and no way to send it.

## What Pandite stores on your computer

Everything below stays on your computer. Removing Pandite and its settings
folder removes all of it.

- **Settings.** The window size, the theme, the size of the gallery strip
  and the folder of your last "Move to" or "Copy to".
- **Folder permissions (Mac App Store version).** macOS lets an app from
  the App Store read only the files and folders you allow. When you allow
  a folder, Pandite keeps that permission so it does not ask again.
- **Your images.** Pandite reads the image files you open and the other
  images in the same folder, to show them. It changes a file only when you
  ask it to: save, crop, resize, rotate, move, copy or delete.

## Text in images

Pandite can recognize text in an image so that you can select and copy it.
This runs on your computer. On Windows it uses the text recognition that is
part of Windows. On macOS and Linux it uses a recognition model that is
built into Pandite. The image and the text never leave your computer.

## The installer

The command `npx pandite` is a separate, optional installer. It is not part
of the Mac App Store or the Microsoft Store version. It contacts GitHub to
find and download the Pandite release, and it sends nothing except the
request for those files. GitHub and npm handle such requests under their
own privacy policies.

## Children

Pandite collects no data from anyone, including children.
