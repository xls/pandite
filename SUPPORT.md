# Support

Pandite is a free, open-source image viewer. Help comes through the project
page on GitHub.

## Report a problem or ask a question

Open an issue at <https://github.com/xls/pandite/issues>.

A good report says:

1. What you did.
2. What you expected.
3. What happened.
4. The Pandite version, and your system: Windows, macOS or Linux, and its
   version.

If one file causes the problem, say what kind of file it is, for example
"a Sony ARW from an A7 IV". Attach the file only if you are happy for it to
be public: issues on GitHub can be read by everyone.

## Find the version

On a command line, run:

```sh
pandite --version
```

On a Mac, select Pandite in Finder and press Command+I. On Windows, the
version is in Settings, Apps, Installed apps.

## Updates

- **Mac App Store and Microsoft Store:** the store installs updates.
- **Installed with `npx pandite`:** run the command again.
- **Downloaded from GitHub:** get the new file from the
  [releases page](https://github.com/xls/pandite/releases).
